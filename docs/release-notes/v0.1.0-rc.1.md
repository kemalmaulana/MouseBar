Early pre-release of MouseBar: a native arm64 macOS menu bar app for SteelSeries Prime Mini Wireless mice. Replaces SteelSeries GG for the mouse.

## What's in it
- Battery in the menu bar (percentage, low/charging/asleep states)
- Panel with battery gauge, connection badge, quick polling and LED controls, banners, save feedback
- Settings in tabs: Performance (DPI presets, polling), Buttons (diagram and action menus), Lighting, Power, Device
- Hardware Check wizard: 9 steps that write test values to the mouse and restore your settings afterwards. Writes a Markdown report.

## Known limits (read before use)
- **Hardware-verified only in part.** Battery over the USB cable was read and matches rivalcfg. Settings writes, the 2.4 GHz dongle, saving to the mouse's memory and active-preset selection are **not yet verified on hardware**.
- The wizard restores the settings MouseBar has stored plus the DPI presets and button remaps you enter. Everything else goes back to factory defaults, and the active DPI preset becomes preset 1.
- Quit SteelSeries GG before use. Its engine can interfere with battery reads.
- No launch at login yet.

## Install
1. Download `MouseBar-0.1.0-arm64.zip` and check the checksum: `shasum -a 256 MouseBar-0.1.0-arm64.zip` should print `8fa39273adf2ed82da87f8d5fcdde8e73f7893a64d3303a3b8a47851db69b914`.
2. Unzip and move `MouseBar.app` to `/Applications`.
3. The app is ad-hoc signed, not notarized. Clear the quarantine flag once: `xattr -dr com.apple.quarantine /Applications/MouseBar.app`.
4. Open it. Use `open -n MouseBar.app --args --demo` to try the UI without a mouse.

Requires macOS 14 or later on Apple silicon.
